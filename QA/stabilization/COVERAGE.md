# Reliability coverage and limits

All databases used by the test tooling are disposable `f01_test_*` databases. Real Docker runs use the accepted digest and scoped recorded runtime cleanup. Controlled failure injection exercises the production state machines; it does not prove unavailable production providers.

| System concern | Executed coverage | Limit |
|---|---|---|
| API/database/contracts | 368 backend tests; additive migration upgrade/downgrade/check; owner constraints/composite FKs; PostgreSQL concurrency; generated client drift and two client tests | Production traffic/capacity not tested |
| Backup/recovery | `test_populated_release_metadata_and_durable_bytes_restore`: actual populated PostgreSQL dump/restore, package bytes, source digest, immutable release history, migration head | Production backup scheduling/storage/restore topology unverified |
| Authentication/session | Signed issuer/audience/expiry/nonce/subject; PKCE single-use browser-bound callback; CSRF/logout; idle/absolute expiry; email verification denial; verified profile update without owner merge; account separation; controlled RSA browser recovery | Actual issuer, Google, delivered magic links and production cookie/domain config absent |
| Planning/AI contract | Context reservations/budgets/concurrency; stale bases/foreign requests; immutable proposals; review; uncertain failure/cancel/result races; revocation during planning; source tool/refusal/response-size/digest/usage validation | One separately bounded real OpenAI agency scenario; broader generated-app functional quality not certified |
| Build/repair/execution | Actual Docker install/typecheck/build/verify; repair; exact source lineage; containment/resource enforcement; duplicate workers/lease fencing; global capacity; revocation/deadline/publication guards; failed update retains last good | Acceptance workload is serial; concurrent production Docker compilation/load qualification unverified |
| Worker loss/stall | Actual owned worker killed during generation; persisted reload; quiet/stall animation stops; uncertainty becomes `PROVIDER_OUTCOME_UNKNOWN`; recovery does not replay provider; queued cancellation, failed repair and retry IDs | Controlled model timing exercises real worker processes |
| Preview/security | Real isolated preview gateway HTTP, strict origin/capability/expiry, opaque iframe, denied foreign access, no host mounts/factory secrets; preview remains after failed update; browser assets/interactions; historical read-only | Generated iframe is excluded from F01 axe scans; one live model test validates publication/verification, not all requested app functions |
| Production releases | Exact-source static export/Build Output package acceptance in Docker; immutable successful/failed evidence; idempotent stage/promotion observations; response-loss reconciliation; unknown outcome blocks blind writes; compensation/restore; revocation; cancellation/deadline; stale generation; last-good live retained after failed redeploy | Production Vercel credentials return HTTP 403; actual public URL health/redeploy/restoration unverified |
| Browser recovery/network | Lost project/build receipt responses; storage restrictions; owner-bound draft reload; historical route; stale context; expired recovery refuses redispatch; offline/reconnect; SSE gaps/duplicates/poll fallback; focus traps and navigation restoration | Tested Chromium/Chrome, not Safari/Firefox or physical devices |
| Accessibility/responsiveness | Both themes, 320/375/720/768/1140/1280/1440 CSS widths where covered; 200%-equivalent 720×500 reflow; reduced motion; axe; keyboard scroll for long saved briefs | No human screen-reader audit or physical zoom/device certification |
| Tooling and interrupts | Existing pipe readiness markers, merged stderr, bounded byte reads, explicit signal ordering, EOF/unwind/owned child reaping; actual disposable DB stays in separate terminal process group for cleanup; full backend and GitHub Actions | Default Chromium install needed host extraction recovery; exact SDK-extractor cause unknown |

All newly discovered implementation failures have targeted regressions in the existing CI. Exact logs, source provenance, skipped checks and external gates are in [VERIFICATION.md](VERIFICATION.md) and checks.json. This is not a bug-free or public-launch certification.
