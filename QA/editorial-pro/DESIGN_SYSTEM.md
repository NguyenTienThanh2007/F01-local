# F01 Editorial Pro foundations

The factory mark and IBM Plex Sans/Mono stay recognizable. Warm paper, disciplined type and a restrained terracotta accent support a calm software studio. The real idea composer, readable saved-work cards and direction/preview workspace provide the visible composition change. Illustrations are labeled examples; saved application covers use actual verified-version descriptors.

Semantic tokens live in apps/web/src/styles/editorial.css, imported after existing layers. All factory surfaces use canvas, surface, surface-muted, surface-raised, ink, muted, line, line-strong, accent/on-accent, success and error pairs. Light uses #f7f4ee/#fffdf8, #282b2d and #b43c2b. Dark uses #1c2024/#24292e/#2d3339, #eeeae3 and #f59b81, with dark text on accent buttons. Small text and state labels pass the recorded AA checks. Color pairs change together to maintain contrast; motion uses transforms/borders/shadows and respects reduced motion.

The desktop workspace puts saved human requests and proposed work on the left, and real application preview/build/release on the right. At 1000px and below the conversation becomes a native disclosure. Dashboard cards use three columns, four on wide desktops, two on tablet, one on phones. Journey remains visible and fills its available width. Technical evidence remains in existing Details/inspectors, including keyboard-constrained mobile dialogs.

The theme bootstrap is a render-blocking same-origin public script, with no new inline CSP permission, credentials, cookies or account writes. Its local preference affects only the factory document. Generated application iframes use their own appearance; native color-scheme inheritance is reset at the shell boundary. The parser observer synchronizes only native appearance controls and disconnects when parsing completes. Runtime System changes and cross-tab preferences remain reactive through the existing theme store.

All backend APIs, data/migrations, confidential OIDC, execution/repair, immutable Brain/source/version evidence, reviewed release protocol, last-good preview/live preservation and sandbox policy remain in place.
