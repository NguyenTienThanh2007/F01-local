# Homepage identity pass — 2026-10-01

Scope: frontend homepage and navigation only. Backend, generated API client,
persistence, authentication and planning submission/cancellation are unchanged.

The former flat hero, conventional textarea frame and static sample lacked a
shared identity. The new hierarchy joins an editorial outcome headline, command
composer and operational sample workspace in a numbered registration frame.
Warm neutral surfaces, terracotta, sharp corner marks and a stepped-gate Pulse
symbol provide the shared visual language.

Changed components: ProductEntry, EntryNavigation, ProjectPulse (instrument
variant), LifecycleDemo, SampleInterface, PlatformIndex; home-only presentation
in ProjectPlanningForm and ProjectStarters. operating-entry.css scopes the new
layout. Dashboard and create route layouts are preserved.

Navigation: Projects, Templates, Connections, Docs, Account, Start a brief.
Templates opens real starter briefs; Connections is explicitly planned; Docs is
a practical guide. Mobile uses the existing accessible navigation Sheet.

The sample has Preview/Blueprint, compact/full viewport, bounded playback and
selectable Trace evidence. All sample data is illustrative. No build, verification,
deployment or application is executed. Create/Run/Manage/Evolve availability is
explicit. Brain, Versions, Deployments, Runtime/Logs, natural-language changes and
external connections are planned. Real planning returns the existing structured
plan, with validation, cancellation, errors and retry preserved.

Verification: typecheck, 24 frontend tests, production build; browser regression
covers planning and local demonstration interactions. Responsive inspection at
375/768/1280/1440px, reduced motion, keyboard menu focus, overflow and WCAG A/AA
axe scans cover homepage, dashboard, create and structured result. Browser tests
use controlled backend responses and do not invoke a live model.
